# GNN 联合部分解补全首轮实验

两层 SparseGATLayer，hidden=64，heads=4；父焊缝头与条件插入头。真实动作包括 (b,r,k,d) 及同一步邻块翻转；父焊缝的两个子块依次放置。
静态图复用焊缝/机器人节点与邻近边，并连接同父子块；动态特征仅来自当前部分路线、端点方向、负载、P+M、插入前后邻块及同轨包络。没有未来 Cmax/WAIT 输入。
合法性通过相同的执行器候选集合落实：机器人资格、X 固定归属、首任务条件、固定模式防合并；每处最多 8 个位置，完整枚举最多 8 个局部方向配置。训练和推理候选完全一致，教师标签缺失即报错，不注入 oracle 动作。
只使用 TRAIN 监督；DEV 无梯度更新。AdamW lr=1e-3，seed=20261027，最终固定 20 epoch，无 DEV 选 checkpoint。首次三 TRAIN 的 1 epoch 为管线烟测，其权重丢弃后重新初始化进行最终训练。
