# 联合方向初解与修复后续实验

seed=20261027；q=[4, 8]；attempts=8；insertion_limit=8；repair_budget=4096。
沿用 FORMAL_SCOPE_V2 与当前 0.0108/0.20m/s、20/30s、0.50m 窗口、0.20m 最短子段。仅使用六个已消耗 DEV 白名单几何。
初解 GREEDY 是旧逐步追加定向流程，BEAM 固定 REGION/RULE 的归属参考，逐块联合选择位置与局部方向；宽度最多 4，优先不同路线结构，单结构最多两个方向。BEAM 每种策略最多四次完整 B32，全部评价后取成功者最低 Cmax，REGION 全失败才尝试 RULE。GREEDY 按原实现运行，调用数如实单列。
修复 OLD 使用旧最大加工负载/局部空走评分、单方向状态；NEW 使用 max(P+M)、sum(P+M) 及同结构最多两个方向状态，Regret 次优仍取不同结构。两方向状态共享 4096 预算，不增加插入总评分次数；最终只选择一个完整候选调度。所有 OLD/NEW 共享同一新初解、逐次相同移除集合和 seed。
修复每次尝试最多一次 B32，成功构造的重复候选也按一次评价，避免因去重改变 OLD/NEW 实际调用预算；唯一候选数另列。只比较 FEASIBLE 的真实 Cmax；DEADLOCK 是有限调度失败。未调用独立 DP/refinement、C2/C3/C4 或独立 certifier。空路线也显式传入空方向；固定模式、覆盖、合法机器人及最终 WELD 操作继续使用必要程序检查。
WAIT 仅在 g36/g45 的新初解确有 WAIT 时做 q8、两次固定 seed 的诊断，不参与三种主选区的总量排名。
