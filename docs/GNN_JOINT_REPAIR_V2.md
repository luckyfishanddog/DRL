# GNN JointRepair V2：扩大 TRAIN 与真实调度反馈实验

本轮已实际完成数据生成、从头训练、六 DEV 配对 B32 与两方法各24轮反馈实验。V2严格改善25/288，明显多于V1的7/288，但未达到NEW的36/288；方向坍缩和零翻转已解除，父选择和长期调度收益仍是短板。

方法：调度反馈驱动的冲突感知联合构造与瓶颈重构。固定拆分模式，方向和邻块翻转由同一次联合插入处理；完整方案仅调用一次 B32，真实 Cmax 严格下降才接纳。
保持两层 SparseGATLayer、hidden=64、heads=4、父选择头和联合候选评分头。没有独立方向阶段或新增启发式算子。

## 5. 回答本轮问题与负结果

1. **是否学会方向和邻块翻转：是，但仍有误差。** 4条真实轨迹/20步的小样本检查最终同时正确记忆全部父选择、插入、方向及7个翻转动作。正式训练后的插入准确率73.45%，方向准确率87.55%；预测方向1占57.16%，实际DEV自主补全占60.36%，已消除原来223/225的极端偏置。教师含翻转时召回447/653=68.45%，DEV自主产生486个含翻转动作，因此不再是“候选存在却永不选择”。这不表示每次翻转都有Cmax收益。
