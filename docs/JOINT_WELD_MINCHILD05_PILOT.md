# 0.50 m 最短子段下的联合分配与排序开发实验

实验日期为 2026-11-04。使用原父模式存档的 INDEPENDENT / parent-mode-v2 九个已用几何。每种方法运行种子 20261031、20261032，每次计 30 秒墙钟。四个单线程工作进程并行，GNN 模型加载、各方法原生初始化和搜索都计时。同步 B32 或原生基线评价可能跨过截止，CSV 的 runtime 记录实际返回时间，Cmax 和解的结构指标均来自截止前的解。

五种方法使用 FORMAL_SCOPE_V2、B32(32) 和同一份原始父焊缝。Y 固定线为 5.5、6.0、6.5 m，X 固定线为既有轨道中心与中心 ±0.5 m，两轴均保留合法中点。MODE_NEW 与 MODE_GNN 使用同一模式提案节奏，FIXED_NEW 保留初始模式。三者复用联合有向补全，插入位置上限为8。GNN 使用旧冻结权重作迁移诊断。WAG、HGA 采用原生初始化、搜索和既有评价路径。主方法使用现有显式方向 B32 路径。

## WAG 差距诊断

- MODE_NEW 最大落后实例为 N55_01。两种子均值按「主方法 / WAG」列出，Cmax 4173.731 / 4108.277，最大加工负载 3952.804 / 3982.349，总空行程 396.522 / 292.003，总等待 140.307 / 0.000，拆分数 3.000 / 2.000。
- MODE_GNN 最大落后实例为 N85_01。两种子均值按「主方法 / WAG」列出，Cmax 4060.014 / 4029.860，最大加工负载 3895.627 / 3897.478，总空行程 420.782 / 508.146，总等待 56.652 / 0.000，拆分数 1.000 / 1.000。

N55_01 的 GNN 最大加工负载均值也低于 WAG，分别为 3875.324 s 和 3982.349 s，但总空行程为 362.896 s 对 292.003 s，总等待为 224.421 s 对 0 s。该例两个种子的 R0、R1 都承担较重负载，WAG 在这种分工下仍能消除等待。N85_01 的三种联合搜索具有相同平均拆分数，MODE_NEW 和 MODE_GNN 的最大负载也接近 WAG。两例的差距优先指向路线组织和关键机器人上的协调代价。总空行程与总等待跨机器人相加，不能直接分解 Cmax。CSV 保留四机器人加工负载，无法据此定位某条焊缝的归属是否不合理。

## 取舍

- **父模式调整有局部收益。** MODE_NEW 接纳了13次带模式提案的改善，分布在9/18次运行。和 FIXED_NEW 在同预算下比较为4胜、1平、4负。N35_01 的两种子均值下降286.004 s，但 N55_01 上反而升高44.441 s。模式调整提供了有效机会，现有提案与补全组合的收益随几何而异。
- **冻结 GNN 在本批更好。** MODE_GNN 对 MODE_NEW 为8胜、1平、0负，三个小规模几何的均值改善约69–152 s。N55_02、N85_02、N85_03 的差值均小于1.3 s。保留它作为后续联合补全候选，若要形成新域训练结果，应使用0.50 m合法目录重新准备训练数据。
- **下一步优先改善排序。** 两种联合重构对 WAG 均为7胜2负，对 HGA 均为9胜。落后 WAG 的两例首先值得比较既有分配下的路线顺序与关键机器人等待，并借鉴 WAG 的路线组织。当前数据未显示普遍的最大加工负载劣势。保留现有 B32 作为共同评价器。
