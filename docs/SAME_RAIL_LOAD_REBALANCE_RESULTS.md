# Same-Rail Load Rebalance（同轨边界重平衡）开发结果

## 结论

本轮定位到的首要瓶颈在**初始化候选的协调可认证性**，而不是 REGION 本身无法构造均衡分配，也不是搜索把均衡初值破坏成极端失衡：

- `MEDIUM_02` 和 `LARGE_04` 的极端负载失衡在初始化结束时已经存在，五个 solver seed 使用同一个确定性失衡初值。
- 两个实例都曾构造出明显更均衡的 REGION/RAIL_BALANCED 候选；`MEDIUM_02` 的这些候选通过 direction DP 后在 B32 中 DEADLOCK，`LARGE_04` 的候选分别在 direction DP 或 B32 中失败。因此最终选中可认证但极端失衡的 `RAIL_SERIAL_BOOTSTRAP`。
- 当前拆分模式和资格约束下存在大量合法同轨转移空间；问题不是“空闲机器人没有合法任务可做”。

据此只实施了路线A：新增默认关闭的 `initialization_same_rail_boundary_rebalance` 开关，在原 `construction_budget=5, kinit_ref=5` 内，用一个同轨联合边界候选替换原低贡献的 `X_ORDER_AWARE` 槽位。没有新增宏步骤、B32预算、ALNS邻域或科学模型。

零搜索诊断中，12个开发几何全部构造出完整合法候选，12/12 direction FEASIBLE、12/12 B32 FEASIBLE、12/12通过独立认证，3个几何得到严格更优认证初值。随后48次开发运行（24个配对）得到：

```text
REGION_FAST_SAME_RAIL vs REGION_FAST_HEURISTIC
6胜 / 17平 / 1负
配对Cmax变化中位数：0.000%
配对Cmax变化均值：-8.791%（负值表示改进）
最大退化：+0.157%
```

改善来自 `N35_S1`、`HW_20262232`、`HW_20262234` 三个几何的两个seed，且均先获得严格更优认证初值，再由后续ALNS继续下降。新方法在多个开发几何上有效、没有严重回归，值得作为**默认关闭的可选初始化增强**保留并冻结当前结构和参数；但这些都是 consumed-development 证据，不能作为新的独立性能主张。

有一项必须披露的执行限制：所有 `Cmax@60` 都只接受60秒截止前完成独立认证的解，截止后结果没有回填；但当前B32调用不能被中途抢占，导致若干进程在60秒后才退出，尤其 `N35_S1` 四次运行的 overshoot 为401--407秒。因此本表是有效的60秒认证检查点比较，却不能把所有运行描述成“进程在60秒硬终止”。下一阶段新的独立验证必须先解决严格进程硬截止；本轮不修改已冻结的B32。

## 3. 唯一代码修改：初始化同轨联合边界候选

实现位于 `src/mrta_search/initialization.py`，接线位于 `src/mrta_search/pipeline.py`：

1. 先调用原 `_construct_region_cooperative_initialization()` 固定上下轨归属和全部WHOLE/Y/X模式。
2. X_SPLIT child保持原机器人固定归属；其余block按X排序，在 `R0/R1` 与 `R2/R3` 上分别形成全部合法连续切点。
3. 以两个轨道切点的笛卡尔积一次性评价 `(b_up, b_low)`，没有上轨优先或下轨优先。
4. 固定代理同时包含每轨归一化最大加工负载和同轨X包络重叠，并用全局Lmax、同轨负载差、空走代理作确定性次级排序。
5. 四条受影响路线调用现有 `_improve_region_route()`，随后使用原 `canonicalize()`、direction DP、B32和独立certifier。
6. 新候选仅替换初始化组合中的 `X_ORDER_AWARE` 槽；REGION、LOAD_FIRST、RAIL_BALANCED、RAIL_MONOTONE及原fallback规则保留。`construction_budget=5`、`kinit_ref=5`没有增加。

这不是搜索期新邻域，也不是CRRR/JRRB评分调整。它解决的是：已知 REGION 轨道分配下，原左右边界/路线组合不能通过协调认证时，用同一预算提供另一种整段连续边界和路线重构。

## 8. 科研判断与停止条件

本轮符合“情况A，但仅限开发证据”：同轨合法迁移确实存在，新增初始化候选在三个不同开发几何、六个配对上同时降低负载与认证Cmax，收益足以抵消初始化开销；最差回归仅0.157%。因此保留默认关闭的可选增强并冻结当前实现，不继续调窗口、权重、候选数，也不叠加GAT。

论文层面的新增认识是：部分几何中两个机器人几乎空闲，是因为均衡初始化候选无法通过协调认证后退化到 serial fallback；在同一轨道上联合改变连续边界并重构路线，可找到另一条B32可行通道。它是对原REGION初始化候选多样性的补充，不是新的独立主方法，也还没有新的独立测试证据。

下一阶段若要形成正式性能主张，需要新的、未参与本轮开发的几何，并以严格硬截止的执行方式独立验证。旧15个正式workbook只用于本报告的事后失效解释，未用于调参或选择候选，不能再次称为新独立测试集。
