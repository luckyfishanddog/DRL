# 共享 GNN 联合初解构造与瓶颈重构

本轮已实际完成共享接口、教师生成、20轮继续训练、六DEV初解与端到端实验。结论为负：共享模型能从空路线完成全部任务，但六DEV只有1例通过B32，与未做完整构造训练的V2相同；目前不能替代Beam作为可靠初解器。

本轮只研究固定 WHOLE/mandatory-Y 模式，同一 JointInsertionGNN 从空路线构造和从部分路线修复。两层 SparseGATLayer、hidden=64、heads=4，联合方向和邻块翻转，显式方向一次B32；无独立方向优化、无启发式回退。

## 4. 本轮六个问题的回答

1. **多少完整教师成功重放：40/46。** 直接复用已有46个TRAIN几何，没有新增PPO实例。成功轨迹共2179个父选择、2210个子块插入动作，保存160个比例状态视图；与原1872个局部动作混合后，去掉13个重复状态—动作对，实际训练4069步。六个目标达到512状态或12秒的重放预算后跳过，不能称为数学上不可重放。搜索限定中间方向与目标方向一致，未穷尽允许临时方向变化的全部顺序；40例已足够本轮训练，因此没有继续扩大搜索或增加教师。完整构造教师没有邻块翻转标签，混合训练的翻转监督来自原有局部轨迹。
2. **能否真正从四条空路线构造：接口与结构构造可以，可靠可调度性尚未实现。** 两个GNN都在六DEV完成全部块的合法构造，各完整初解只运行一次B32；V2和Shared均只有1/6可调度。Shared没有读取Beam路线或归属，JointGeometry没有routes属性；其父选择、机器人、插入位置、方向和邻块翻转均由同一网络逐步决定。V2成功在g21，Shared成功在g15，混合训练未提高成功数。
3. **神经初解比Beam如何：明显不足。** Beam为6/6可调度，总初解耗时31.044秒；V2为1/6、11.391秒；Shared为1/6、11.452秒。Shared唯一成功的g15初解Cmax为2543.703秒，比Beam的1653.687秒高890.017秒。V2在g21得到2557.409秒，优于该例Beam的2690.964秒，但共享模型在该例DEADLOCK；没有因这一负结果重新选模型或种子。失败样本的耗时短不能解释为求解速度优势。
